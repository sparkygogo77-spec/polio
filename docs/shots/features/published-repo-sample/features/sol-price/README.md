# Live SOL price

The price of SOL in dollars, from a public price source, refreshed every few seconds.

**Needs:** none, it runs on the static page as published.

## Inputs

- `every` — Refresh every (seconds) (default `30`)
- `format` — Format (default `$1.23`); one of `$1.23`, `1.23`, `$1.2K`
- `show` — Show (default `price`); one of `price`, `24h change`

Attach it in the builder by typing “sol price” or “solana price” in a part's box.
