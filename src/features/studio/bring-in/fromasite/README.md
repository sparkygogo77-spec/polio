# studio/bring-in/fromasite

Bringing a site in (from a link, a zip or a repo), split by topic. `../FromASite.tsx` re-exports what it always exported.

| File | Holds |
| --- | --- |
| `bring.tsx` | Asking the routes, import stages and `ImportStrip`, `clearImportLine`, `HEADLESS`, pictures and screens from a zip, `landAsBrought`, `KeepFrom`, `BringHost` |
| `FromASite.tsx` | `FromASite`: the import door. One component |
| `bits.tsx` | `Brought`, `Details`, `Waiting` |
